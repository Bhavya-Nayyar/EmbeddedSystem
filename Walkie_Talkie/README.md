## Hardware

1. INMP441 I2S Microphone (2x)

2. MAX98357A I2S Amplifier (2x)

3. 4 ohm 3W speaker (2x)

4. nRF24L01 + PA/LNA radio module (2x)

5. STM32 Nucleo F446RE

6. ESP32

7. nRF24L01 Base Adapter Board (2x)
